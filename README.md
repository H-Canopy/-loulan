## ✨ 这是一次怎样的体验

一幅关于楼兰的交互式艺术想象。从盐白废墟出发，让一座丝路绿洲城邦在指尖短暂显影。

| 环节 | 内容 |
|---|---|
| **今昔显影** | 鼠标移动 / 触屏拖动 / 滑杆，让「现在的遗址」与「往昔的盛景」相互显影 |
| **记忆之印** | 盛景停留后，天空中的信物可带你进入城内 |
| **市集记忆展廊** | 一间临水商铺，正面四龛陈列：商旅彩绘、织物、陶罐、记事木牌 |
| **展品阅读** | 轻触展品即可点亮历史，查看介绍与创作说明 |
| **文字诗帘** | 四句竖排诗句错落垂落，逐字流动，触碰时如丝绸般被拨动、渐染朱砂 |

## 🖱️ 基本操作

- **移动 / 轻触**：局部揭开遗迹，看见往昔
- **滑杆**：控制今昔转换比例
- **让盛景停留**：完整观看历史画面，不自动消失
- **记忆之印 → 循迹入城**：进入市集记忆展廊
- **返回遗迹 / Esc**：随时回到现在

## 🧱 技术栈

- **Vite + TypeScript**
- **Three.js / 原生 Web**：画面分层、显影与视差
- **HTML / CSS**：动态文字、展廊与交互界面

## 🚀 本地运行

```bash
npm install
npm run dev
```

## 🛠️ 发布说明

本仓库为 **GitHub Pages 构建产物**，部署于子路径 `/-loulan/`。修改源码后需重新构建并更新本站：

```bash
# 构建时需禁用 Git Bash 的路径转换，避免 base 被改写为绝对路径
MSYS_NO_PATHCONV=1 npx vite build --base=/-loulan/
```
